# Partner / supporter logos

Drop each partner's logo here, then wire it up in `index.html` (the "Supported by"
section, `#partners`).

## How to add a logo

1. Save the file in this folder using the filename referenced in the commented-out
   `<img>` tag for that partner, e.g.:
   - `sierra-club-sf.svg`
   - `civic-joy-fund.svg`
   - `streets-for-all-sf.svg`
   - `greening-projects.svg`
   - `fauvescraper-studio.svg`
   - `walk-sf.svg`
   - `slowdown-sf.svg`
   - `green-sf-now.svg`
   - `sf-public-space-collective.svg`
2. In `index.html`, uncomment the `<img>` line inside that partner's tile and delete
   the text-only `<span class="partner-name">…</span>` fallback.

## Tips

- **SVG preferred** (crisp at any size). PNG at ~2× display size also works.
- Logos render inside a tile at up to **60px tall**. Use a transparent background.
- Keep the `alt` text as the organization's name.
